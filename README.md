# Premium Frontend Developer Portfolio

A modern freelancing portfolio for a frontend engineer focused on SaaS dashboards, analytics platforms, and enterprise web applications.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- shadcn/ui-style primitives
- Framer Motion
- Lucide icons
- Dark/light mode

## Scripts

```bash
npm run dev
npm run lint
npm run build
```

The local development server runs at [http://localhost:3000](http://localhost:3000).
